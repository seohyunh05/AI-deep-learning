# AI & Deep Learning Projects

A collection of machine learning and deep learning projects developed using Python and Jupyter Notebook.

This repository documents practical applications of neural networks, image classification, regression, model training, and performance evaluation.

## Projects

### 1. Korean Consonant Classification
Developed neural network models to classify handwritten Korean consonants.

- Implemented and compared Multilayer Perceptron (MLP) and Convolutional Neural Network (CNN) architectures.
- Experimented with different learning rates and model configurations.
- Evaluated model performance using accuracy and loss.
- Saved the selected trained model for testing and inference.

**[View Project](./Korean%20Consonant%20Classification/)**

### 2. Fashion-MNIST Classification
An image classification project using the Fashion-MNIST dataset.

- Explored neural network-based image classification.
- Practiced model training and evaluation.

**[View Notebook](./fashion_mnist_classification.ipynb)**

### 3. Salary Regression
A machine learning exercise focused on regression analysis.

- Explored relationships between numerical variables.
- Practiced regression modeling and prediction.

**[View Notebook](./salary_regression.ipynb)**

## Technologies

- **Programming Language:** Python
- **Development Environment:** Jupyter Notebook, Google Colab
- **Deep Learning:** PyTorch
- **Data Processing & Visualization:** NumPy, Matplotlib
