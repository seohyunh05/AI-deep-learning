# AI & Deep Learning Projects

A collection of artificial intelligence, machine learning, and deep learning projects developed using Python.

This repository documents practical experience in neural networks, image classification, regression analysis, transfer learning, model training, and performance evaluation.

## Projects

### 1. Korean Consonant Classification

A deep learning project focused on classifying handwritten Korean consonants using neural networks.

- Implemented and compared Multilayer Perceptron (MLP) and Convolutional Neural Network (CNN) architectures.
- Applied image preprocessing and data augmentation techniques.
- Experimented with different learning rates and model configurations.
- Evaluated model performance using accuracy and loss.
- Selected and saved the best-performing model for testing and inference.

**[View Project](./Korean%20Consonant%20Classification/)**

### 2. Fashion-MNIST Classification

An image classification project using the Fashion-MNIST dataset.

- Explored neural network-based image classification.
- Practiced image preprocessing and model implementation.
- Trained and evaluated classification models.

**[View Notebook](./fashion_mnist_classification.ipynb)**

### 3. ResNet18 Transfer Learning

A deep learning project exploring transfer learning using the ResNet18 architecture.

- Explored convolutional neural networks and residual learning.
- Applied transfer learning techniques for image classification.
- Practiced adapting neural network architectures for classification tasks.
- Explored model training and performance evaluation.

**[View Notebook](./resnet18_transfer_learning.ipynb)**

### 4. Salary Regression

A machine learning project focused on regression analysis and numerical prediction.

- Explored relationships between numerical variables.
- Practiced regression modeling and prediction.
- Applied fundamental machine learning concepts to regression tasks.

**[View Notebook](./salary_regression.ipynb)**
